# Ехидные крестики — сайт-каталог схем вышивки

Сайт-каталог авторских схем вышивки крестом Елены Козыревой.
Сделан на Python + Flask, HTML, CSS и обычном JavaScript (без сложных
библиотек и сборщиков).

**Слоган:** «Вышивка с характером. Схемы со смыслом.»

> ⚠️ Сейчас в каталоге лежат **демонстрационные** данные и графические
> заглушки. Настоящих схем, цен и фотографий в проекте нет — их нужно
> добавить самостоятельно через админ-панель.

---

## Что нового

Раньше схемы хранились в файле `data/patterns.json`, и добавить схему
можно было только вручную в «Блокноте». Теперь у сайта есть **закрытая
админ-панель** по адресу `/admin`, а данные хранятся в базе **SQLite**
(файл `data/catalog.db`).

Что это даёт:

- схемы, категории и фотографии добавляются **через удобные формы**, без
  редактирования файлов;
- у каждой схемы есть **черновик** — можно готовить её, не показывая
  покупателям, а потом **опубликовать** одной кнопкой;
- удаление **безопасное**: схема прячется, но её всегда можно вернуть;
- есть **резервные копии** базы (раздел «Резервные копии» в панели);
- настройки сайта (название, тексты, контакты, фирменные изображения)
  меняются прямо в панели.

А ещё у сайта появились **личные кабинеты покупателей** и **живое
сообщество**:

- **Регистрация и вход.** Покупатель может завести аккаунт, указать имя
  и получить личную страницу `/account`.
- **Личная библиотека.** Схемы, на которые у покупателя есть право
  скачивания, собираются в одном месте — файлы схем (PDF и др.) выдаются
  только владельцу, по защищённой ссылке.
- **Хвастики.** Покупатель может выложить фотографию отшитой работы;
  каждая работа проходит **ручную проверку** администратором.
- **Отзывы.** Отзывы к схемам тоже проходят проверку; человеку, который
  действительно купил схему на сайте, автоматически ставится значок
  **«Покупка подтверждена»**.
- **Кнопки «Поделиться».** Схемой и работой можно поделиться в соцсетях.
- **Фирменный вид.** Первый экран собран как вышивка: аватар сообщества
  крупно в блоке заголовка, «вышитая» типографика, текстильные плашки.

Подробная пошаговая инструкция для панели — в отдельном файле
**[ADMIN_GUIDE.md](ADMIN_GUIDE.md)**.

## Что уже работает

- Главная страница с приветственным блоком, каталогом и блоком «О проекте».
- Фильтр каталога по названию и категории, сортировка по цене и названию.

  «Поделиться».
- Отзывы к схемам с проверкой и значком «Покупка подтверждена».
- Фирменный первый экран: аватар сообщества крупно, вышитая типографика,
  текстильные плашки.
- Закрытая админ-панель `/admin`: каталог схем, категории, покупатели,
  библиотека и права, отшивы, отзывы, настройки главной, резервные копии.
- Страница 404 для несуществующих адресов и схем.
- Адаптивный дизайн для телефона, планшета и компьютера.
- Плавные анимации с уважением к настройке `prefers-reduced-motion`.
- Автоматические тесты.

## 1. Как установить Python

1. Откройте сайт <https://www.python.org/downloads/>.
2. Скачайте Python версии 3.10 или новее и запустите установку.
3. **Важно:** на первом экране установщика поставьте галочку
   **«Add Python to PATH»** (Добавить Python в PATH).
4. Нажмите «Install Now» и дождитесь окончания.

Проверить установку можно в терминале (командной строке) командой:

```
python --version
```

Должно появиться что-то вроде `Python 3.12.1`.

> **Где открыть терминал?**
> В Windows: откройте папку с проектом в Проводнике, щёлкните по адресной
> строке, наберите `cmd` и нажмите Enter. Либо нажмите правой кнопкой мыши
> в папке проекта → «Открыть в терминале».

## 2. Как создать виртуальное окружение

Виртуальное окружение — это отдельная «песочница» для библиотек проекта,
чтобы они не мешали другим программам на компьютере.

В папке проекта выполните:

```
python -m venv venv
```

Активируйте окружение:

- **Windows (cmd):** `venv\Scripts\activate`
- **Windows (PowerShell):** `venv\Scripts\Activate.ps1`
- **macOS / Linux:** `source venv/bin/activate`

После активации в начале строки терминала появится `(venv)`.

## 4. Первый запуск: настройка администратора

Прежде чем входить в админ-панель, нужно один раз задать логин и пароль.
**Пароль нигде не хранится в открытом виде** — в базу попадает только его
защищённый отпечаток (хеш).

В папке проекта выполните:

```
python setup_admin.py
```

Команда попросит придумать логин и пароль. Пароль должен быть достаточно
длинным и надёжным — программа сама подскажет, если он слабоват.

Можно задать данные и одной строкой (удобно для автоматизации):

```
python setup_admin.py --username elena --password "Ваш-Надёжный-Пароль"
```

Если администратор уже создан, повторный запуск предложит сменить пароль.

> **Совет по безопасности.** Придумайте пароль, которого нет ни в одном
> словаре, и никому его не показывайте. Пароли вроде `admin123` не
> подойдут — программа их не примет.

## 5. Как запустить сайт

Из папки проекта (там, где лежит `app.py`):

```
python app.py
```

В терминале появится:

```
Сайт «Ехидные крестики» запущен!
Откройте в браузере:  http://127.0.0.1:5000
Административная панель:  http://127.0.0.1:5000/admin
```

Откройте браузер:

- публичный сайт — <http://127.0.0.1:5000>
- админ-панель — <http://127.0.0.1:5000/admin>

Первый запуск создаёт базу `data/catalog.db`, если её ещё нет, и **не
удаляет** уже сохранённые данные.

> **Секретный ключ.** Чтобы вход в панель сохранялся между перезапусками,
> задайте ключ `EK_SECRET_KEY`. Если его не задать, при каждом запуске
> используется временный ключ — работать будет, но администратору придётся
> входить заново после каждого перезапуска сервера.
>
> Windows (PowerShell):
> ```powershell
> $env:EK_SECRET_KEY="длинная-случайная-строка"
> ```
> macOS / Linux:
> ```bash
> export EK_SECRET_KEY="длинная-случайная-строка"
> ```

## 7. Как добавить новую схему

Все действия выполняются в админ-панели, файлы править не нужно.
Подробная пошаговая инструкция — в **[ADMIN_GUIDE.md](ADMIN_GUIDE.md)**.

Кратко:

1. Откройте <http://127.0.0.1:5000/admin> и войдите.
2. Раздел **«Добавить схему»**.
3. Заполните название, описание, цену и характеристики.
4. Загрузите главное изображение и (по желанию) фотографии и фрагмент 10×10.
5. Нажмите **«Сохранить черновик»** — схему пока видите только вы.
6. Проверьте вид кнопкой **«Предпросмотр»**.
7. Нажмите **«Опубликовать»** — схема появится в каталоге.

После публикации схема видна покупателям и попадает в корзину.

## 8. Как поменять фирменные цвета

Все цвета собраны в самом начале файла **`static/css/style.css`**,
в разделе `:root`:

```css
:root {
  --color-linen:       #F4F0E8;  /* Молочный лён — основной фон */
  --color-eucalyptus:  #A4B4A2;  /* Пыльный эвкалипт — мягкие подложки */
  --color-pine:        #56645A;  /* Тёмная хвоя — заголовки, кнопки, шапка */
  --color-chocolate:   #6A4C3E;  /* Тёплый шоколад — основной текст */
  --color-hydrangea:   #738BC5;  /* Гортензия — декоративные акценты */
  --color-terracotta:  #C4705A;  /* Терракота — точечные акценты */
  ...
}
```

Поменяйте HEX-значение — и цвет обновится по всему сайту. Например,
чтобы сделать акцент ярче:

```css
  --color-terracotta:  #B85C3F;
```

После правки обновите страницу в браузере (F5). Если цвет не меняется,
нажмите **Ctrl + F5** (жёсткое обновление).

> Совет: проверяйте контраст текста и фона — он должен оставаться
> читаемым (стандарт WCAG AA).

## 9. Как проверить работу корзины

Корзина работает в браузере и хранит данные в `localStorage` под ключом
`echidnye_krestiki_cart`.

**Ручная проверка по шагам:**

1. Откройте каталог на главной странице.
2. Нажмите «Ознакомиться» у любой схемы — откроется её страница.
3. Посмотрите основное изображение (клик — увеличение).
4. Прокрутите до блока «Рассмотреть схему поближе» и нажмите на фрагмент.
5. Закройте окно (крестик, Escape или клик вне картинки).
6. Нажмите «Добавить в корзину» — кнопка станет «Добавлено ✓»,
   а счётчик в шапке увеличится.
7. Вернитесь в каталог и добавьте вторую схему.
8. Нажмите на значок корзины — откроется страница `/cart`.
9. Удалите один товар (крестик справа) — сумма пересчитается сразу.
10. Нажмите «Выбрать ещё» — вернётесь в каталог.
11. Перезагрузите страницу (F5) — корзина сохранится.

**Повторное добавление одной схемы дубликат не создаёт** — это цифровой
товар, он покупается один раз.

**Проверка через консоль браузера** (F12 → вкладка Console):

```js
getCart()        // список id в корзине
getCartCount()   // количество схем
getCartTotal()   // итоговая сумма
addToCart(2)     // добавить схему с id 2
removeFromCart(2)// удалить схему с id 2
```

## 10. Как сделать резервную копию

Проще всего — в админ-панели, раздел **«Резервные копии»**: там кнопка
«Создать копию» и список уже сделанных копий с датами.

Вручную копии лежат в папке **`data/backups/`** (файлы вида
`catalog_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.db`). Сама база — файл **`data/catalog.db`**.

Чтобы сохранить все данные, достаточно скопировать файл `data/catalog.db`
или любую копию из `data/backups/` в надёжное место.

> Перед крупными изменениями всегда делайте копию — это занимает секунду,
> а спокойствия прибавляет надолго.

## 11. Личные кабинеты и библиотека

У сайта есть **личные кабинеты покупателей**. Это бесплатно и не требует
никаких внешних сервисов.

**Как покупатель попадает в кабинет:**

1. Нажмите **«Войти»** в шапке сайта.
2. Если аккаунта ещё нет — **«Зарегистрироваться»**: нужны имя, адрес
   электронной почты и пароль.
3. После входа открывается страница **`/account`**.

**Что внутри кабинета:**

- **Библиотека** (`/account/library`) — все схемы, на которые у человека
  есть право скачивания. Рядом с каждой — кнопка скачивания файла схемы.
- **Заказы** (`/account/orders`) — история заказов и их состав.
- **Мои работы** (`/account/projects`) — загруженные хвастики и их статус.
- **Мои отзывы** (`/account/reviews`) — отзывы и их статус проверки.
- **Настройки** (`/account/settings`) — имя, пароль, согласия.

**Как выдаётся право на скачивание (самое важное):**

Файлы схем лежат в защищённой папке `protected/` и **никогда** не отдаются
по прямой ссылке. Скачать схему может только тот, кому администратор
выдал право. Право появляется двумя путями:

- **Автоматически** — когда покупка была подтверждена на сайте
  (источник `site`). Такому человеку в отзывах показывается значок
  **«Покупка подтверждена»**.
- **Вручную** — администратор выдаёт право в панели
  (источник `manual`). Это для покупок вне сайта; значка «Покупка
  подтверждена» при этом не будет — так честнее.

Как именно выдавать права — по шагам в
**[ADMIN_GUIDE.md](ADMIN_GUIDE.md)**.

> **Письма с подтверждением.** Сайт работает в честном локальном режиме:
> настоящие письма никуда не отправляются, а ссылка подтверждения и
> ссылка восстановления пароля **показывается прямо на странице**. Так
> удобно проверять всё локально. Настройка задаётся в `config.py`
> (`EMAIL_DEV_MODE`); когда подключите настоящую почту, режим нужно
> выключить.

> **Файлы схем пока не загружены.** Чтобы в библиотеке появились кнопки
> скачивания, положите настоящие файлы схем (PDF, Saga, Paradise и т. п.)
> в папку `protected/` и привяжите их к схемам через панель
> (раздел **«Библиотека и права»**).

## 12. Хвастики и отзывы

Это два способа показать живое сообщество — и оба проходят **ручную
проверку**, ничего не публикуется само.

**Хвастики (галерея отшитых работ)** — страница `/gallery`:

1. Войдите в кабинет и откройте **«Мои работы»** (`/account/projects`).
2. Загрузите фотографию отшитой работы и подпишите её.
3. Работа попадает на проверку — статус **«На проверке»**.
4. После одобрения администратором работа появляется в общей галерее.

У работы есть кнопка **«Поделиться»**, а автор может **отозвать согласие**
на публикацию — тогда работа убирается из галереи.

**Отзывы** — страница `/reviews`:

1. Откройте страницу схемы и нажмите **«Оставить отзыв»** (или зайдите
   через кабинет).
2. Отзыв проходит проверку и только потом публикуется.
3. Если человек купил эту схему **на сайте**, рядом появляется значок
   **«Покупка подтверждена»**.

Заголовки и тексты разделов «Хвастики» и «Отзывы» на главной можно
менять в панели — раздел **«Настройки главной»**.

Чтобы не было спама, действует короткая пауза между отзывами и работами
(настраивается в `config.py`: `REVIEW_COOLDOWN_MINUTES`,
`PROJECT_COOLDOWN_MINUTES`). Повторять один и тот же текст много раз
нельзя.

**Пока отзывов и работ нет** — сайт честно пишет, что их пока нет, и
предлагает стать первым. Никаких выдуманных отзывов и фотографий «для
красоты» на сайте нет.

## 13. Автоматические тесты

Тесты проверяют и публичную часть сайта, и админ-панель: вход и выход,
создание черновика, загрузку фото, публикацию и снятие с публикации,
безопасное удаление, настройки, а также работу корзины после перехода
на базу данных. Отдельная группа тестов покрывает личные кабинеты,
защищённую выдачу файлов, хвастики и отзывы.

Запуск из папки проекта:

```
python -m pytest tests/ -v
```

Ожидаемый результат — все тесты `PASSED`, например `64 passed`.

> **Важно:** тесты **не трогают** рабочую базу `data/catalog.db`.
> Для проверок создаётся отдельная временная база, которая удаляется
> после теста.

pip install pytest

## Что работает в демонстрационном режиме

Честно перечисляю, что пока не подключено к настоящей продаже:

- **Оплата не подключена.** Кнопка «Оформить заказ» ведёт на страницу,
  которая честно сообщает: «Онлайн-оформление заказов появится позже».
  Никаких платёжных полей и ложных сообщений об оплате нет.
- **Письма не отправляются по-настоящему.** Сайт работает в локальном
  режиме (`EMAIL_DEV_MODE`): ссылки подтверждения и восстановления пароля
  показываются прямо на странице, чтобы всё можно было проверить локально.
- **Файлы схем пока не загружены.** Папка `protected/` пуста, поэтому
  в личной библиотеке не будет кнопок скачивания, пока вы не положите
  туда настоящие файлы схем и не привяжете их через панель.
- **Нет каталога реальных схем** — все данные и картинки в проекте
  тестовые.
- **Нет выдуманных отзывов и работ.** Пока их не добавили настоящие
  покупатели, сайт честно пишет «пока пусто» и предлагает стать первым.
- **Ссылка на ВКонтакте не задана** — пока она пустая, пункт в подвале
  не показывается.
- **Логотип (ехидна) хранится, но на первом экране не выводится** —
  по вашему решению в блоке заголовка показывается только аватар
  сообщества крупно. Сам файл никуда не пропал.

Архитектура готова к развитию: когда понадобится принимать настоящие
заказы, достаточно подключить оплату — структура страниц, кабинетов и
корзины менять не придётся.

## Публикация в интернете

Для локальной разработки в `config.py` включён режим `DEBUG = True`:
он удобен (сайт сам перезагружается при правках), но **в продакшене его
обязательно нужно отключить**:

```python
DEBUG = False
```

Также смените `SITE_URL` на адрес вашего сайта — он используется в
SEO-тегах. Для настоящего размещения сайт запускают не через
`python app.py`, а через настоящий веб-сервер (например, Gunicorn или
uWSGI) — это стандартный путь для Flask-проектов.

**Пароли и ключи в коде не хранятся.** Секретный ключ задаётся через
переменную окружения `EK_SECRET_KEY`, а пароль администратора — только
в виде хеша в базе.
